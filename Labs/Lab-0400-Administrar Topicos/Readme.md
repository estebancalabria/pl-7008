# Requisitos

* Tener el Enviroment Creado
* Conocer el ID de enviroment
* Tener creado el agente "Real Estate Booking Service" del laboratorio anterior

# Pasos

* Ir a la pagina de copilot
  * https://copilotstudio.microsoft.com/environments/<ID_ENVIROMENT>/home
* Ir al agente "Real Estate Booking Service"
* Ir al solapa de Temas/Topics
* Desactivar el topico "Volver a Empezar"

## Crear un tema con copilot

* Agregar un topico desde una descripcion con Copilot
  * Nombre : Detalles del cliente
  * Detalles : Preguntarle al cliente su nombre y direccion de correo
* Se te abre la ventana para editar el tema.
  * Decirle a Copilot que lo modifique
    * "Que en la pregunta de cual es el correo primero agradezca al nombre ingresado en la pregunta anterior y luego diga si por favor provea su correo electronico"
* Luego modificar
  * "Resume la información recopilada en una tarjeta adaptativa."
* Luego
  * "Agrega una nueva pregunta de opción múltiple para pedirle al usuario que confirme si los datos son correctos, con dos opciones: Sí o No."

## Crear un tema desde cero

1. Selecciona la pestaña **Temas** en la barra superior de *Real Estate Booking Service*.
2. Haz clic en **+ Agregar un tema** y selecciona **Desde cero**.
3. Selecciona el ícono de **Detalles** para abrir el cuadro de diálogo de detalles del tema (puede que debas seleccionar **Más > Detalles**).

Completa los siguientes campos:

- **Nombre**:

```
Reservar visita
```

- **Nombre para mostrar**:

```
Reservar una visita inmobiliaria
```

- **Descripción**:
- 
```
Seleccionar la propiedad y la fecha solicitada y crear una solicitud de reserva
```

- **Nombre para mostrar del modelo**:
```

Reservar visita

```

4. Haz clic en **Guardar**.
```


Select the property and requested date and create a booking request

```

- **Nombre para mostrar del modelo**:
```

Book Showing

```

4. Haz clic en **Guardar**.
```
